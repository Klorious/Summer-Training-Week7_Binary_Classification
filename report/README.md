# Binary-classification report

This directory is reserved for the Binary Classification Rundown only.

The final report must be authored in Overleaf and should contain:

1. Assignment objective and execution environment.
2. Human Good/Bad scoring rubric and threshold.
3. Three representative Good and three representative Bad annotation examples.
4. Data splits and class distributions.
5. VGG16, ResNet18, and ResNet50 architectures and hyperparameters.
6. Training/validation loss and accuracy curves.
7. Full 500-image candidate-pool prediction distribution.
8. Agreement count/rate, confusion matrices, Precision, Recall, F1-score,
   and Cohen's Kappa on the locked 100-image reference set.
9. For each model: five agreement cases, five disagreement cases, and at
   least two high-confidence errors.
10. Conclusion, AI-tool disclosure, GitHub link, and Binary W&B link.

Keep the final report limited to the binary-classification requirements
listed above.
